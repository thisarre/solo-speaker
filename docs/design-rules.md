# Solo Speaker Design Rules

Solo Speaker utilise une direction Studio Light / Studio Dark :
Geist + Geist Mono, accent indigo, surfaces calmes, bordures hairline, densité premium.

Règles obligatoires :
1. Ne jamais utiliser border-black, text-black, border-2 ou outline noir dans l’UI applicative.
2. Les bordures utilisent toujours les tokens border/line.
3. Les cards utilisent une bordure légère, radius 12px maximum sauf exception.
4. Les inputs ont une hauteur compacte : 38-42px.
5. Les boutons ont une hauteur compacte : 34-38px.
6. Les labels sont petits : 12-13px, medium, muted.
7. Les ombres sont très légères.
8. L’accent principal est indigo.
9. Geist est la police principale.
10. Geist Mono est réservé aux badges, timers, shortcuts et metadata.
11. Le Speaking Mode est le seul endroit où le noir profond est dominant.
12. Toute nouvelle page doit être comparée visuellement au prototype Studio avant validation.
